# azraasiksoy.github.io

My personal portfolio, set up as a detective-style pinboard. Notes, a photo album and my publications are pinned to the board. Click any of them to zoom in.

Plain HTML, CSS and JavaScript, no frameworks or build step. To run it locally, just open `index.html` in a browser.

```
index.html       the board and its cards
css/style.css    layout and card positions
js/board.js      zooming and the photo album
images/          the board background and my photos
```

The board illustration is a single 16:9 image, and the cards are placed as percentages of it, so the layout scales to any screen size. On phones, the cards stack in a column instead.
